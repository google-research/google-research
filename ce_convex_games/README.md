# Intractability of Approximate Correlated Equilibria in Two-Player Convex Games

This directory contains the paper
[*Intractability of Approximate Correlated Equilibria in Two-Player Convex Games*](CE_in_Convex_Games.pdf).

This paper was generated by the Cogentic harness.

## Abstract

We show that computing an ε-approximate normal-form correlated equilibrium
(ε-CE) in two-player convex games admits no fully polynomial-time approximation
scheme (FPTAS), resolving a central open question of Anagnostides et al.
Specifically, in the standard first-order black-box oracle model on the unit
Euclidean balls, we construct a family of ½-strongly convex quadratic games with
costs in [0, 1] and Euclidean Lipschitz constant L < √d on which every
randomized algorithm outputting a (1/d)-CE with probability at least 2/3
requires at least exp(Ω(d^{1/16})) = d^{ω(1)} oracle queries, regardless of
internal running time or the support size of the output distribution.
